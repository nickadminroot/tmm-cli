# Public TMM skills agent guide

This repository contains only portable skills and the standalone
metric-synthesis runtime. It must not acquire private TMM source, checkout
paths, credentials, generated task artifacts, or private Git history.

## Ownership

- `skills/tmm-cli` owns CLI installation, security, commands, diagnostics, and
  resume/admission guidance.
- `skills/tmm-yaml` owns the public projection of the physical YAML contract
  and complete educational examples.
- `skills/metric-synthesis` owns the numerical runtime, its schemas, examples,
  tests, and synthesis-to-YAML handoff.
- The private TMM server owns remote validation, account admission, and returned
  artifacts. Do not duplicate its implementation here.

Keep each skill self-contained. Relative references must resolve from its own
directory. Do not introduce a global installer, a second package manager, or a
mirror of the private repository.

## Checks

From `skills/metric-synthesis/scripts`:

```bash
uv sync --extra dev --locked
uv run --locked pytest -q ../tests
uv run --locked ruff check .
```

From the repository root, the equivalent absolute-path smoke is:

```bash
uv run --locked --project skills/metric-synthesis/scripts \
  python -m msynth.cli models
```

Keep `uv.lock` generated by `uv`; do not edit it by hand. Keep generated
environments, build output, caches, and user request/output directories out of
Git.
