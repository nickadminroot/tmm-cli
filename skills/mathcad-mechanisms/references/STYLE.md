# Стиль листа и API переноса

Источник соглашений — переписанные JPG 112–156 и генераторы в `scripts/`. Здесь «скан» означает конкретный предоставленный лист, а не автоматически действующий норматив.

## Оформление и порядок

Использовать короткие русские заголовки по образцу: «Исходные данные», «Начальные приближения», «Метрический синтез механизма», «Кинематическое исследование», «Аналоги скоростей», «Аналоги ускорений», «Приведённые моменты сил», «Приведённые моменты инерции», «Работа сил», «Кинетостатический силовой анализ». Не заменять их длинными рассуждениями или англоязычными заголовками.

Сначала определения, затем вычисление и контроль, затем график. Геометрические схемы показывают точки и звенья, а не декоративные иллюстрации. На диаграмме — функция от обобщённой координаты и обозначения осей; вспомогательные кривые имеют различимый тип линии. Расчётное положение `f` выделяется на плане/годографе. Для годографа сохранить и модуль реакции, и её направление.

Книжная двухколоночная страница — монтаж блоков. В рабочем Mathcad определения должны идти **сверху вниз в вычислительном порядке**. Не копировать монтаж так, чтобы правая колонка зависела от ещё не определённой левой. Генераторы намеренно строят последовательный лист. Они не обещают совпадения переносов строк, шрифта мелких подписей и разбивки на печатные страницы. Широкие символьные матрицы и длинные результаты необходимо проверить при нативном открытии и печати.

## Обозначения

Во всех формулах, индексах, таблицах, подписях и схемах используй короткую
научную нотацию ТММ. Звенья обозначай целыми цифрами: `1`, `2`, `3` и т. д.;
для неподвижной стойки в формулах и чертежах используй `0`, а в физическом YAML
оставляй обязательный идентификатор `ground`. Точки и кинематические пары
обозначай заглавными латинскими буквами: `A`, `B`, `C`, `H`. Короткий индекс
после латинской буквы допустим только для устранения совпадений, например
`P3`; описательные имена для точек и пар не вводи.

Переменные и индексы оформляй стандартными символами с короткими индексами:
`l_1`, `φ_2`, `ω_1`, `ε_1`, `X_A`, `Y_A`, `V_A`, `a_A`, `R_21`, `M`, `J`.
Не заменяй их длинными именами вроде `connecting_rod_length`,
`angle_of_body_2` или `velocity_of_point_A`. Пояснения пиши в тексте, примечании
или подписи; обязательные ключи YAML и API (`bodies`, `joints`, `ground` и
другие) не переименовывай. Не смешивай латинские и похожие кириллические
буквы.

| Смысл | Запись в Python-адаптере |
|---|---|
| Координаты точки / центра масс | `X_A(φ)`, `Y_S2(φ)` |
| Ориентация звена | `φ_2(φ)` |
| Аналоги угловых скорости / ускорения | `ω_q2(φ)`, `ε_q2(φ)` |
| Аналоги линейных скорости / ускорения | `V_qS2X(φ)`, `a_qS2X(φ)` |
| Действительные величины | `ω(φ)`, `ε(φ)`, `a_S2X(φ)` |
| Приведённые моменты / инерция | `M_прДВ`, `M_прC`, `M_прΣ`, `I_прI`, `I_прII`, `I_прΣ` |
| Приведённые силы / масса при линейной координате | `F_прC(s)`, `F_прДВ(s)`, `m_прΣ(s)` |
| Работа | `A_C`, `A_ДВ`, `A_Σ` |
| Инерционные нагрузки | `Φ_2X`, `Φ_2Y`, `M_Φ2` |
| Реакции | `R_21X`, `R_21Y`, `R_21`, `φ_R21` |
| Система равновесия и решение | `A`, `B`, `DR`; раздельные номера групп |

`_` отделяет **литеральный подстрочный индекс** символа Mathcad. Например, `I_прII` — одно имя, не массив. `[i]` и `[i,j]` — индексирование массива при `ORIGIN=0`. Регистр важен: `A_S` и `A_s` различны. Латинские и кириллические похожие буквы также различны; копировать имена из выбранного примера целиком.

В изображении книги некоторые имена набраны с верхним `пр`; адаптер сохраняет смысл индекса в литерном подстрочном имени, чтобы не путать его с возведением в степень. Это явное ограничение типографической точности, не изменение физической величины.

## Единицы и знаки

Числа в исходниках используются в СИ без прикреплённых единиц Mathcad; подписи указывают размерности. Углы задаются как `60*deg` и вычисляются в радианах. Деление на `deg` применяется при выводе. При переходе к размерностным единицам Mathcad необходимо последовательно переделать весь лист, а не добавить `m` к нескольким исходным числам.

`ω_q1=-1` означает выбранное отрицательное направление поворота при возрастающей обобщённой координате. `ε_1=ω_q1*ε`. Силы сопротивления определяются по направлению движения и фазе, а не только по модулю заданной нагрузки. Вес направлен вниз в принятой системе. Взаимные реакции должны менять знак при переходе к соседнему звену.

Mathcad `atan2(x,y)` в этих листах получает сначала компоненту X, затем Y. В независимом Python-проверочнике используется обычный NumPy `atan2(y,x)`. Не переносить порядок аргументов механически. Для непрерывных углов следить за ветвью и разрезом; направления реакций сравнивать по модулю 2π.

## Минимальная памятка API

| Операция | Пример |
|---|---|
| Определение | `b.D('l_AB','3.8*l_OA')` |
| Вывод, отдельно от печатного контроля | `b.E('l_AB','0.219')` |
| Функция | `b.D('X_A(φ)','l_OA*cos(φ_1(φ))')` |
| Производная / интеграл | `diff(X_A(φ),φ,2)`, `intg(M(q),q,0,φ)` |
| Диапазон | `rng(0,2*π,deg)`; третий аргумент — **второе значение**, не шаг |
| Вектор / матрица | `[x,y,z]`, `[[a,b],[c,d]]` |
| Столбец / транспонирование | `col(R,0)`, `A.T` |
| Система | `b.given('x+y==5','x-y==1'); b.solve(['x','y'])` |
| Параметрическая система | `b.solve(['φ_2','φ_3'],args=['φ'])` |
| Кусочная функция | `b.piece('F(s)', [('100','s<.1')], default='0')` |
| График | `b.plot(('φ/deg','ω(φ)'),x_bounds=(0,360),caption='Угловая скорость')` |
| Полярный годограф | `b.plot(('φ_R21(φ)','R_21(φ)'),polar=True)` |
| Примечание / восстановленный параметр | `b.note('…')`, `b.D('g',9.81,why='Восстановлено по весам.')` |

`b.solve` для одной неизвестной получает скаляр, для нескольких — вектор. Не добавлять `[0]` к скалярному `Find`. Для выводимой матрицы указывать `shape=(rows,cols)`, например `b.E('DR(f).T',shape=(1,9))`; это размер области вывода, а не подмена результата.

Для графика по углу всегда фиксировать `x_bounds`: `(0,360)` для `0…2π` при выводе через `/deg`, `(0,720)` для `0…4π`. Это границы математической оси X, а не параметр `width` региона; автоматический Mathcad-диапазон может округлиться наружу и оставить пустой участок.

Вызов `sample` воспроизводит книжную цепочку «сетка → массив → коэффициенты сплайна → новая функция». `lspline`, `cspline`, `linterp` — разные операции; сохранять именно выбранную в примере, пока нет обоснования изменить её. Не выбирать гладкий сплайн только ради красивой кривой силы с физическим изломом.

`BatchWorksheet` откладывает промежуточную раскладку областей до записи, не меняя исходную библиотеку. Это позволяет быстро собирать большие листы. Класс не подходит для редактирования, которое опирается на координаты ещё не разложенных областей.
